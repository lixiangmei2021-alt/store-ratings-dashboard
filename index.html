立即更新评分

从当前页面启动一次 GitHub Actions 抓取。

只需配置一次。之后每次点“手动更新”，都会在本页直接启动 GitHub Actions，不需要打开仓库。

  1. 创建令牌

    点下面的按钮，GitHub 令牌页会自动勾选所需权限。

    打开 GitHub 创建令牌 改用 Fine-grained（权限更小）
  2. 确认权限

    经典令牌确认已勾选 repo 与 workflow；Fine-grained 令牌请选择仓库 store-ratings-dashboard，并把仓库权限 Actions 设为 Read and write。创建令牌的账号需要该仓库的写入权限（本人或协作者）。

  3. 生成并粘贴

    点页面底部的 Generate token，复制以 ghp_ 或 github_pat_ 开头的令牌，粘贴到下面输入框。

在 GitHub 里找不到入口？点开看菜单路径

右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。

Fine-grained 路径：同一页面的 Fine-grained tokens → Generate new token。

令牌只保存在这台电脑的当前浏览器（localStorage），不会上传到网站，也不会写入公开仓库。建议在 GitHub 创建时把有效期设为任意较短天数，用完可随时删除。

备用：查看运行页

更新通常需要 1–2 分钟，完成后页面会自动刷新。其他访客仍可正常查看，但只有保存了令牌的浏览器才能启动更新。

尚未配置更新令牌。

如果点“手动更新”后直接跳到 GitHub 仓库、看不到这个弹窗，说明浏览器还在用旧页面：按 Ctrl+F5（Mac 为 ⌘+Shift+R）强制刷新一次即可。
